# QUICK REFERENCE: Actuary vs Software Engineer

## 30-Second Summary

**Actuary**: Stable, predictable, exam-heavy path. Takes 2-3 years to first job. $8M lifetime earnings. Job security 8/10.

**Software Engineer**: Flexible, higher ceiling, skill-based. Start immediately after graduation. $7.5M lifetime (average) to $11.5M (FAANG). Job security 5/10.

**Default recommendation**: Software Engineer (faster entry, more options, can pivot to actuary later)

## Reality Check: What People Don't Tell You

### Actuary Reality

**The Good**:
- Job exists, stable
- Pay is genuinely good ($120K-$250K range)
- Work-life balance excellent after exams
- Recession-proof career
- Can work until 65+ (no age discrimination)

**The Bad**:
- Exams dominate your 20s completely
- Social life suffers for 7-10 years
- 60% don't finish fellowship (FSA/FCAS)
- First job very hard to get without internship
- Work can be boring (lots of Excel reconciliation)
- Must live in insurance cities (Hartford, not glamorous)

**The Ugly Truth**:
- You'll spend weekends studying while friends party
- You'll fail exams (everyone does)
- You'll watch peers buy houses while you're still entry-level
- You'll question if it's worth it (around exam 4-5)
- But if you finish: Very rewarding career

### Software Engineer Reality

**The Good**:
- Many job opportunities
- High pay possible ($150K-$500K)
- Creative, intellectually stimulating
- Remote work common
- Can start immediately

**The Bad**:
- Age discrimination is REAL (after 40-45)
- Burnout common (50% experience it)
- Constant learning exhausting
- Layoffs frequent (every 5-7 years)
- Imposter syndrome common

**The Ugly Truth**:
- You'll be laid off at least once in your career
- You'll see younger engineers overtake you
- You'll feel obsolete if you don't keep learning
- Your job won't exist at 55-60 (most engineers out by then)
- But early career: Very lucrative and exciting

## The Hybrid Strategy (Best of Both)

### Start Software Engineer → Pivot to Actuary

**Why this works**:
- Get immediate income ($75K-$100K)
- Save money while working
- Pass actuarial exams on the side (1-2 per year)
- Pivot to actuary with financial cushion + programming skills
- Become modern actuary (exams + coding)

**Timeline**:
- Age 22-24: Work as software engineer, pass 2 exams
- Age 24-25: Apply to actuarial roles (with exams + coding)
- Age 25-30: Work as actuary, finish exams
- Result: Higher starting salary, better candidacy, financial security

**Downside**:
- 2-3 years "lost" in software (not on actuarial track)
- Studying while working full-time (hard)
- Might like software too much to leave

**Probability of success**: 60% (higher than direct actuary path)

## Expected Value Calculation

### Software Engineer
- 15% FAANG path: $11.5M lifetime
- 50% average path: $7.5M lifetime
- 35% struggling path: $3.9M lifetime

**Expected value**: 0.15($11.5M) + 0.50($7.5M) + 0.35($3.9M) = **$6.86M**

**Conclusion**: Software engineer has higher expected value (+$710K), but also higher variance.

**Risk-adjusted**:
