# UAlbany Student Decision: Actuary vs Software Engineer

## Your Specific Situation

**Location**: University at Albany, New York
**Decision**: Actuary vs Software Engineer
**Framework**: Step-by-step practical analysis, no metaphors

---

## Step 1: What Each Career Actually Requires

### Actuary Requirements

| Requirement | Details | Time Investment |
|-------------|---------|-----------------|
| Degree | Math, Statistics, Actuarial Science, Economics | 4 years |
| Exams | SOA or CAS series (7-10 exams) | 7-10 years while working |
| Study Hours | 300-400 hours per exam | 15-20 hrs/week for years |
| Internship | Required for most entry jobs | Summer before senior year |
| Programming | Python/R now expected | Learn during undergrad |
| GPA | 3.4+ preferred | Continuous effort |

### Software Engineer Requirements

| Requirement | Details | Time Investment |
|-------------|---------|-----------------|
| Degree | CS, IT, Math, or related (or none) | 4 years or self-taught |
| Certifications | Optional (AWS, Google, etc.) | 1-3 months each |
| Portfolio | GitHub projects, apps built | Build during school |
| Internship | Helpful but not required | Summer(s) |
| Programming | Multiple languages required | 1-2 years intensive |
| GPA | Less important than skills | Matters less |

## Step 4: Time Investment Comparison

### Actuary Timeline from UAlbany

```
Year 1 (Freshman): Take calculus, probability courses. Start studying for Exam P.
Year 2 (Sophomore): Pass Exam P. Take statistics courses. Start Exam FM prep.
Year 3 (Junior): Pass Exam FM. Apply to 40-60 internships (December). Get internship.
Year 4 (Senior): Pass 1 more exam. Apply to 50+ full-time jobs. Hopefully get offer.
Years 5-7: Work entry-level, pass 2-3 more exams, reach ASA.
Years 8-11: Pass remaining exams, reach FSA.

TOTAL: 10+ years of studying and exams to reach full credential.
```

### Software Engineer Timeline from UAlbany

```
Year 1 (Freshman): Learn programming fundamentals (Python, Java).
Year 2 (Sophomore): Data structures, algorithms. Build first projects.
Year 3 (Junior): Build portfolio. Internship(s). Learn frameworks.
Year 4 (Senior): Apply to jobs. No exams required.
Years 5+: Work and learn on the job. No mandatory credentials.

TOTAL: 4 years of school, then continuous learning on the job (no exams).
```

## Step 6: Day-to-Day Work Reality

### Actuary Daily Work

**Entry-level (Years 1-3):**
- Update Excel models
- Run reserve calculations
- Data cleaning and validation
- Prepare reports for senior actuaries

**Mid-level (Years 4-7):**

- Manage team

- Code reviews
- Testing
- Documentation
- Learn codebase

**Mid-level (Years 3-5):**
- Design systems
- Lead small projects
- Mentor juniors
- Technical decisions
- On-call rotations (some companies)

**Senior (Years 6+):**
- Architecture decisions
- Cross-team coordination
- Technical strategy
- Mentoring
- Still writing code

## Step 7: Skills You Need to Assess

### For Actuary - You Need:

1. **Math ability**: Can you score 90%+ on calculus and probability exams with moderate effort?
   - If yes → Actuary possible
   - If no → Actuary will be painful

2. **Exam discipline**: Can you study 15-20 hours per week for 7-10 years while working full-time?
   - If yes → Actuary possible
   - If no → You will likely not finish exams

3. **Delayed gratification**: Can you accept lower pay years 1-5 while studying for higher pay years 10+?
   - If yes → Actuary makes sense
   - If no → Software engineering pays more immediately

4. **Risk tolerance**: Are you okay with a narrower job market in exchange for stability?
   - If yes → Actuary fits
   - If no → Software engineering has more options

### For Software Engineering - You Need:

1. **Problem-solving**: Do you enjoy breaking down complex problems into logical steps?
   - If yes → Software engineering fits
   - If no → Consider other options

2. **Self-teaching**: Can you learn new technologies independently from documentation?
   - If yes → You will thrive
   - If no → You will fall behind (tech changes fast)

3. **Building things**: Do you get satisfaction from creating working programs?
   - If yes → Good fit
   - If no → This job will feel pointless

4. **Handling ambiguity**: Can you work with unclear requirements and figure things out?
   - If yes → You will do well
   - If no → You will be frustrated often

## Step 12: My Direct Assessment for You

### Choose Actuary If:
1. You genuinely enjoy mathematics and scored well in calculus/probability
2. You can commit to studying 15-20 hours/week for 7-10 years
3. You value long-term stability over short-term flexibility
4. You are willing to relocate to Hartford, NYC, or other insurance hubs
5. You want a clear, structured career path with defined milestones
6. You don't need creative expression in your work
7. You can delay gratification (lower pay now, higher pay later)

### Choose Software Engineering If:
1. You enjoy building things and solving puzzles with code
2. You want to start earning competitive salary sooner
3. You want geographic flexibility or remote work options
4. You prefer learning on the job vs. formal exams
5. You want more career options (startup, big tech, freelance, entrepreneurship)
6. You're okay with continuous self-learning but not formal testing
7. You want to stay in or near the Albany area (more options)

### Red Flags for Actuary:
- If you struggle in math courses (C's or below)
- If you hate standardized tests
- If you can't imagine studying for 10 years
- If you refuse to relocate from Albany/upstate NY

### Red Flags for Software Engineering:
- If you find programming frustrating, not challenging
- If you don't enjoy building things
- If you want a completely predictable career path
- If you don't want to continuously learn new technologies

## Step 13: Hybrid Options to Consider

### Option 1: Start SWE, Pivot to Actuary Later
- Get CS degree, work as SWE for 3-5 years
- If you want more stability, start actuarial exams while working
- Programming skills will help in modern actuarial work
- Risk: Harder to break into actuarial field later

### Option 2: Data Science (Middle Ground)
- Combines math skills and programming
- More jobs than actuarial, more stability than pure SWE
- No mandatory exams
- Can pivot to either field later

### Option 3: Quantitative Finance
- Uses math skills like actuary
- Higher pay potential than both
- Requires strong programming + math
- More competitive to enter

## Final Recommendation

**Based on practical factors for a UAlbany student:**

**If you're unsure → Start with Software Engineering**

Reasons:
1. Faster to know if it's right for you (build projects, see if you enjoy it)
2. More job options near Albany and remotely
3. Can always add actuarial exams later if you want
4. Lower risk of wasted years if it doesn't work out
5. Skills transfer to many fields (data science, finance, consulting)

**If you're CERTAIN about actuarial → Start exams immediately**

Reasons:
1. Exam progression takes years - can't rush it
2. Every semester you wait delays your career
3. Pass 2 exams in college = much better internship chances
4. The sooner you start, the sooner you finish
