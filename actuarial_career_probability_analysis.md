## Step 1: Calculate Base Hiring Probability

### Given Data:
- **Total qualified candidates**: 3,000 per year
- **Entry-level positions available**: 700 per year
- **Competition ratio**: 3,000 candidates : 700 positions = 4.29:1

### Base Probability Calculation:
```
Probability = (Available Positions) / (Total Qualified Candidates)
Probability = 700 / 3,000
Probability = 0.2333...
Probability = 23.33%
```

**Base hiring probability: 23.33%**
