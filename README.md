## 🎯 Quick Summary

### Actuary
- **Time to job**: 2-3 years
- **Entry salary**: $65K-$75K
- **Lifetime earnings**: $8.1M
- **Job security**: 8/10
- **Best for**: Top 10% math ability, high discipline, risk-averse

### Software Engineer
- **Time to job**: 0-6 months
- **Entry salary**: $70K-$120K
- **Lifetime earnings**: $5.8M-$11.5M (varies widely)
- **Job security**: 5/10
- **Best for**: Enjoy coding, risk-tolerant, want flexibility

### Default Recommendation
**Software Engineer** - faster entry, more options, can pivot to actuary later

## ⚠️ Reality Check

### What No One Tells You

**Actuary**:
- ✓ Stable career, good pay, excellent work-life balance (after exams)
- ✗ Exams dominate your 20s, 60% don't finish, hard to get first job

**Software Engineer**:
- ✓ High pay, many opportunities, immediate start
- ✗ Age discrimination after 40, burnout common, layoffs frequent

### Both Paths Lead to Success
- Both earn $100K-$250K
- Both lead to comfortable retirement
- Both require hard work
- Choice depends on your personality

---

## 🚀 Hybrid Strategy (Recommended)

**Best approach**:
1. Start as software engineer (age 22-24)
2. Save money, pass 2-3 actuarial exams on side
3. Pivot to actuary (age 24-26) if you want stability
4. Finish actuarial exams with financial cushion

**Why this works**:
- Immediate income
- Keeps both options open
- Programming skills valuable for modern actuaries
- Financial security while studying exams
