# Actuarial Career Prospects Analysis

### Given Market Conditions:
- **Total openings per year**: 2,000
- **Entry-level positions per year**: 700

## PART 1: Base Probability Calculation

### Step 1: Raw Competition Ratio
```
Entry-level positions available = 700
Qualified candidates = 3,000

Base probability = 700 / 3,000 = 0.2333 = 23.33%
```

**Base hiring probability: 23.33%**

## PART 3: Competitive Position Analysis

### Typical Entry-Level Actuarial Candidate Profile:
- **Exams**: 2-3 exams passed (most competitive have 2-3)
- **Education**: Actuarial Science, Math, Statistics, or related degree
- **Internships**: 1-2 actuarial internships (highly valued)
- **Technical Skills**: Excel (required), some have Python/R/SQL
- **GPA**: 3.5+ typically expected

### Your Competitive Disadvantages:
1. **No internships**: Major disadvantage. Internships often lead to full-time offers.
2. **No experience**: All entry-level candidates lack experience, so this is neutral.
3. **Self-taught technical skills**: Positive, but common among candidates.
4. **Small projects**: Positive, but limited impact without internships.

### Competitive Position Relative to Average Qualified Candidate:
- **Average qualified candidate**: Has 2-3 exams + internship experience
- **Your position**: 3 exams + no internship + technical skills + projects

**Estimated competitive multiplier**: 0.60-0.75x (you are less competitive than average due to no internship)

---

## PART 4: Adjusted Probability Calculation

### Calculation:
```
Base probability = 23.33%
Competitive multiplier = 0.60-0.75x (estimated range)

Adjusted probability = 23.33% × 0.60 = 14.00% (lower bound)
Adjusted probability = 23.33% × 0.75 = 17.50% (upper bound)
```

**Adjusted hiring probability range: 14% - 17.5%**
