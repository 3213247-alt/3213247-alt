## PART 1: Hiring Probability Calculation

### Step 1: Basic Probability Calculation

**Formula**: Probability = (Available Positions) / (Competing Candidates)

**Calculation**:
- Entry-level positions: 700
- Qualified candidates: 3,000
- **Basic probability = 700 / 3,000 = 0.2333 = 23.33%**

### Step 2: Accounting for Candidate Quality Distribution

Not all 3,000 candidates are equally qualified. Typical distribution:
- **Highly competitive** (2-3 exams, internships, strong projects): ~500 candidates
- **Moderately competitive** (1-2 exams, some skills): ~1,500 candidates  
- **Minimally qualified** (0-1 exam, basic skills): ~1,000 candidates

**Hiring reality**: Employers typically hire from the top 2 tiers first.

**Adjusted calculation for average candidate**:
- If you're in the "moderately competitive" tier competing for remaining spots:
- Top tier takes ~400 positions
- Remaining positions: 700 - 400 = 300
- Remaining candidates: 1,500 + 1,000 = 2,500
- **Probability = 300 / 2,500 = 12%**

- **Probability range: 35-50%**
