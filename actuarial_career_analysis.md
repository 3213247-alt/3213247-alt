# Actuarial Career Prospects Analysis
## Step-by-Step Calculation and Career Path Comparison

### Key Statistics Provided:
- **Total actuarial openings per year**: 2,000
- **Entry-level openings per year**: 700
- **Qualified candidates competing annually**: 3,000 (constant)
- **Target year**: 2031

---

## PART 1: HIRING PROBABILITY CALCULATION

### Step 1: Basic Probability Calculation
**Given:**
- Entry-level positions available: 700
- Qualified candidates: 3,000

**Basic probability formula:**
```
P(hired) = Available positions / Total qualified candidates
P(hired) = 700 / 3,000 = 0.2333 = 23.33%
```

### Step 2: Percentage Range Analysis

**Best Case Scenario (Upper Bound):**
- Assumes some candidates drop out, apply to multiple fields, or are geographically constrained
- If effective competition reduces to ~2,500 candidates:
  - P(hired) = 700 / 2,500 = **28.0%**

**Realistic Scenario (Mid-Range):**
- Accounts for:
  - Candidates applying to multiple positions (some get multiple offers)
  - Geographic mismatches
  - Some candidates not truly "qualified" despite being counted
  - Market fluctuations
- **Range: 20% - 25%**

**Worst Case Scenario (Lower Bound):**
- If competition increases or positions decrease:
- If effective competition increases to ~3,500 (including underqualified):
  - P(hired) = 700 / 3,500 = **20.0%**

**Conservative Worst Case:**
- If only 600 positions available (10% reduction):
  - P(hired) = 600 / 3,000 = **20.0%**

### Step 3: Final Probability Range

**LIKELIHOOD OF GETTING HIRED: 20% - 28%**

**Most Realistic Single Estimate: 23%**

## PART 2: EXAM REQUIREMENTS BY 2031

### Current State (2024):
- Entry-level typically requires: **2-3 exams**
- Competitive entry-level: **3-4 exams**

### Projected State (2031 - 7 years from now):

**Analysis:**
- Actuarial profession has been increasing exam requirements over time
- 2010s: 1-2 exams for entry-level
- 2020s: 2-3 exams for entry-level
- Trend suggests continued increase in competition

**2031 Projection:**
- **Minimum for entry-level**: 3 exams (likely)
- **Competitive for entry-level**: **4 exams** (very likely)
- **Highly competitive**: 4-5 exams

**Conclusion: YES, 4 exams will likely be needed by 2031 for competitive entry-level positions.**

## PART 3: CAREER PATH COMPARISON

### Path A: University of Albany (Full-Time Student)
**Timeline:**
- Year 1-4: Bachelor's degree (Actuarial Science/Math)
- During degree: Pass 1 exam
- After graduation: Work part-time, pass 2 more exams (2-3 years)
- Learn Python, R, SQL, do small projects
- **Total time to 3 exams**: ~5-7 years from start
- **By 2031**: Would have 3 exams (possibly 4 if started early)

**Advantages:**
- Structured curriculum
- Career services/networking
- Internship opportunities (though not taken)
- Credential recognition

**Disadvantages:**
- No internship = major disadvantage
- No experience = competing against those with internships
- Higher cost (if applicable)
- Delayed entry into workforce

**Hiring Probability with this profile:**
- 3 exams + degree + technical skills + NO experience/internship
- **Estimated probability: 15-22%** (below average due to no experience)

### Path B: SUNY Empire College (Part-Time While Working)
**Timeline:**
- Work part-time throughout
- Self-study for exams while working
- Pass exams independently
- Learn Python, R, SQL through self-study/projects
- **Total time to 3 exams**: Variable (depends on work schedule)
- **By 2031**: Could have 2-4 exams depending on dedication

**Advantages:**
- Work experience (even if not actuarial) = transferable skills
- No gap in employment history
- Lower cost
- Demonstrates work ethic/time management
- Can potentially get non-actuarial experience that's relevant

**Disadvantages:**
- Less structured support
- Slower exam progress potentially
- Less networking opportunities
- May need to work harder to prove qualifications

**Hiring Probability with this profile:**
- 3 exams + degree + technical skills + work experience (non-actuarial)
- **Estimated probability: 18-25%** (slightly better due to work experience)
