# Actuary vs. Software Engineering: Step-by-Step Decision Guide for UAlbany Student

## Step 1: Understand What Each Career Actually Does

### Actuary - Day-to-Day Reality

**What actuaries do:**
- Analyze financial risk using mathematics and statistics
- Build models to predict insurance claims, mortality, or financial losses
- Set insurance premiums and reserves
- Ensure companies comply with insurance regulations
- Present findings to executives and regulators
- Work primarily in: Insurance companies, consulting firms, government agencies

**Typical tasks:**
- Build Excel models (still common despite automation)
- Write Python/R scripts for data analysis
- Review mortality tables or claims data
- Calculate reserves (money set aside for future claims)
- Write reports explaining technical findings to non-technical people
- Attend meetings about pricing strategies

**Work environment:**
- Office-based (some remote work available)
- 40-50 hours/week after exams (45-60 hours/week during exam periods)
- Collaborative but also independent analytical work
- Deadlines tied to regulatory filings (quarterly, annual)

### Software Engineer - Day-to-Day Reality

**What software engineers do:**
- Write code to build applications, websites, or systems
- Design software architecture
- Debug and fix code issues
- Collaborate with product managers, designers, other engineers
- Deploy and maintain software systems
- Work in: Tech companies, startups, banks, healthcare, government, virtually every industry

**Typical tasks:**
- Write code in languages like Python, Java, JavaScript, C++, etc.
- Review other engineers' code (code reviews)
- Attend standup meetings (daily team sync)
- Debug production issues
- Design new features or systems
- Write tests for code
- Deploy code to servers/cloud

**Work environment:**
- Can be fully remote, hybrid, or office-based
- Hours vary: 40-50 hours/week typical, but can be 60+ at startups/FAANG
- Highly collaborative (pair programming, team projects)
- Agile development cycles (sprints, releases)

## Step 2: Entry Requirements Comparison

### Actuary Entry Requirements

**Education:**
- Bachelor's degree (Math, Statistics, Actuarial Science, Economics, Finance)
- UAlbany offers actuarial science program - CHECK if you're in it or can switch

**Exams (CRITICAL - This is the barrier):**
- Must pass actuarial exams to progress
- Entry-level: Need 2-3 exams (Exam P, Exam FM, sometimes Exam IFM)
- Each exam: 3-6 months study, 200-400 hours
- Pass rates: 40-50% (difficult)
- Total exams: 7-10 exams over 5-10 years to reach Fellowship
- Cost: $200-500 per exam attempt

**Skills needed:**
- Strong math (calculus, probability, statistics)
- Excel proficiency
- Python or R programming (increasingly required)
- SQL for data queries
- Communication skills (explain complex math to non-math people)

**Internships:**
- CRITICAL - Very hard to get first job without internship
- Apply sophomore/junior year
- Competitive (10-15% acceptance rates at top companies)
- Geographic constraint: Most internships in Hartford CT, Des Moines IA, Chicago IL, NYC, Boston MA

**Timeline to first job:**
- Best case: 2-3 exams + internship = job offer senior year
- Realistic: 2-3 exams + internship = job search 3-6 months after graduation
- Without internship: Much harder, may take 12+ months

### Software Engineering Entry Requirements

**Education:**
- Bachelor's degree in Computer Science (most common)
- OR: Bootcamp + portfolio (possible but harder)
- OR: Self-taught + strong portfolio (hardest path)
- UAlbany has Computer Science program - CHECK if you're in it or can switch

**No exams required:**
- No professional licensing exams
- Technical interviews instead (coding challenges, system design)

**Skills needed:**
- Programming languages (Python, Java, JavaScript most common)
- Data structures and algorithms
- Software development practices (version control, testing)
- Problem-solving ability
- Can learn on the job

**Internships:**
- Helpful but NOT as critical as actuarial internships
- Many software engineers get first job without internship
- More opportunities available (tech companies hire many interns)
- Can be remote (more flexible geographically)

**Timeline to first job:**
- Best case: Strong portfolio + internship = job offer senior year
- Realistic: 3-6 months job search after graduation
- Can start applying immediately (no exam barrier)

## Step 3: Career Progression and Earnings

### Actuary Career Progression

**Year 1-2 (Entry-level Analyst):**
- Salary: $60,000-$75,000 (2025 dollars)
- Passing exams while working
- Doing data preparation, basic modeling
- 45-50 hours/week (more during exam periods)

**Year 3-5 (Associate Level - ASA/ACAS):**
- Salary: $85,000-$110,000
- 4-6 exams passed
- More complex modeling, some project management
- 45-50 hours/week

**Year 5-10 (Fellowship - FSA/FCAS):**
- Salary: $120,000-$180,000
- All exams passed (7-10 total)
- Senior modeling, strategic decisions, managing teams
- 45-50 hours/week

**Year 10+ (Senior/Management):**
- Salary: $180,000-$300,000+
- Director/VP level
- Strategic risk management, executive presentations
- 45-50 hours/week

**Key points:**
- Progression tied to exam passing (can't skip steps)
- Raises come with each exam passed ($3,000-$10,000 per exam)
- Slower early career growth than software engineering
- More stable, predictable progression
- Career viable until 60+ (less age discrimination)

### Software Engineering Career Progression

**Year 1-2 (Junior Engineer):**
- Salary: $70,000-$120,000 (varies by location/company)
- Writing code, learning systems
- 40-50 hours/week (can be 60+ at startups/FAANG)

**Year 3-5 (Mid-level Engineer):**
- Salary: $100,000-$180,000
- More complex features, mentoring juniors
- 40-50 hours/week

**Year 5-10 (Senior Engineer):**
- Salary: $150,000-$250,000
- System design, technical leadership
- 40-50 hours/week

**Year 10+ (Staff/Principal/Management):**
- Salary: $200,000-$500,000+ (FAANG can be $500K-$1M+)
- Architecture decisions, managing teams
- 40-60 hours/week

**Key points:**
- Faster early career growth (higher starting salaries)
- Progression based on performance, not exams
- Can switch companies for big raises (common)
- Higher ceiling at top companies (FAANG)
- More variable (some engineers plateau, others excel)
- Age discrimination exists (harder to get hired 50+)

## Step 4: Job Market Reality (2025)

### Actuary Job Market

**Entry-level positions:**
- DECREASING - 30-40% fewer entry-level jobs than 2015
- Competition: HIGH (many exam-passers competing for fewer jobs)
- Geographic concentration: Must be willing to relocate to insurance hubs
- Remote work: Limited for entry-level (more common mid-career)

**Why decreasing:**
- Automation replacing entry-level tasks
- Companies hiring fewer, more experienced actuaries
- AI tools handling basic calculations

**Mid-career (5+ years):**
- BETTER - More opportunities
- Companies prefer experienced actuaries
- Remote work more available

**Long-term outlook:**
- Entry-level: DIFFICULT (4/10 difficulty)
- Mid-career: GOOD (7.5/10)
- Senior: EXCELLENT (8.5/10)

### Software Engineering Job Market

**Entry-level positions:**
- LARGE - Many more openings than actuarial
- Competition: MODERATE (many applicants but also many jobs)
- Geographic flexibility: Can work remote, many cities have tech jobs
- Remote work: Common (many fully remote positions)

**Why large:**
- Every industry needs software
- Tech companies constantly hiring
- Startups always need engineers
- Digital transformation across industries

**Mid-career (5+ years):**
- EXCELLENT - High demand
- Can switch companies easily for raises
- Many opportunities

**Long-term outlook:**
- Entry-level: MODERATE (6/10 difficulty - more jobs but more competition)
- Mid-career: EXCELLENT (8/10)
- Senior: EXCELLENT (8.5/10) BUT age discrimination risk

## Step 5: Work-Life Balance

### Actuary Work-Life Balance

**During exam years (first 5-10 years):**
- POOR - Must study 15-20 hours/week outside work
- Weekends spent studying
- Social life limited
- Vacation planning around exam dates
- Stressful (failing exams = career impact)

**After exams (Fellowship achieved):**
- GOOD - 45-50 hours/week typical
- Predictable schedule
- Vacation days actually usable
- Less stress
- Sustainable long-term

**Overall:**
- Years 1-10: 5/10 work-life balance (exams dominate)
- Years 10+: 8/10 work-life balance (excellent)

### Software Engineering Work-Life Balance

**Early career:**
- MODERATE - 40-50 hours/week typical
- Can be 60+ at startups/FAANG
- On-call rotations (responding to production issues)
- Learning new technologies (ongoing, but less intense than actuarial exams)

**Mid-career:**
- MODERATE-GOOD - 40-50 hours/week typical
- Still on-call rotations (can be stressful)
- Need to keep learning (tech changes fast)
- Can be better if you find right company

**Overall:**
- Years 1-10: 6.5/10 work-life balance
- Years 10+: 7/10 work-life balance (can be good, but varies by company)

**Key difference:**
- Actuary: Bad early (exams), good later
- Software: Moderate throughout (varies by company)

## Step 9: Decision Framework

### Choose Actuary If:

1. **Strong math ability** (top 10% - can handle calculus, probability easily)
2. **High discipline** (can study 15-20 hours/week for 7-10 years)
3. **Value stability** over rapid growth
4. **Willing to relocate** to insurance hubs (Hartford, Des Moines, Chicago)
5. **Risk-averse** personality
6. **Want predictable career** progression
7. **Can secure internship** (critical for actuarial)
8. **Age 18-25** (earlier is better for actuarial)

### Choose Software Engineering If:

1. **Problem-solving ability** (can break down complex problems)
2. **Enjoy coding** (or willing to learn)
3. **Value flexibility** (remote work, many industries)
4. **Want faster early career growth**
5. **Comfortable with change** (tech evolves quickly)
6. **Prefer no exams** (technical interviews instead)
7. **Want higher ceiling** (FAANG can pay $500K+)
8. **Geographic flexibility** (can work remote)

### Red Flags (Don't Choose Actuary If):

- Average math ability → Better options exist
- Low persistence → Won't finish exams
- Hate studying → Exams will be miserable
- Can't relocate → Entry-level actuarial jobs geographically limited
- Want rapid wealth → Entrepreneurship or tech better

### Red Flags (Don't Choose Software If):

- Hate debugging → Core part of the job
- Can't handle ambiguity → Tech projects often unclear
- Want very stable → Tech has more layoffs than insurance
- Don't like learning new things → Technology changes constantly
