**Cavity**: Assumes person can learn technical skills in 12-18 months. What if learning is slower?

**Reality Check**:

- Demand is structural (infrastructure needs, security threats), not cyclical
- **Risk**: LOW-MODERATE (saturation unlikely in 10-year window)
