- User estimates 30-40% are entry-level
- Therefore: ~720-960 entry-level positions
- User rounds to "~1,000 entry-level jobs"

**VERIFICATION:**

1. **BLS Data Check:**
   - Need to verify the 2,400 figure
   - This includes ALL actuarial openings (entry, mid, senior, replacements)

2. **Entry-level percentage (30-40%)**
   - This is SPECULATION
   - Could be 20%, could be 50%
   - NO PUBLIC DATA on breakdown

3. **Indeed/Glassdoor listings (294-1,435)**
   - These are SNAPSHOT data at one point in time
   - Do NOT equal annual totals
   - Listings stay posted 30-60 days typically
   - Annual total would be: Listings × (365 / average days posted)

**CALCULATION EXAMPLE:**
- If 294 listings at any moment
- Average posting duration: 45 days
- Annual unique listings: 294 × (365 / 45) = ~2,385 total postings
- But this includes duplicates, reposts, multiple locations for same role

**VERDICT: The 1,000 entry-level estimate is REASONABLE but unverified**
